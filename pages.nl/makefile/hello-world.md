# hello-world

> Basissyntax voor het definiëren van een regel om tekst te tonen.
> Meer informatie: <https://www.gnu.org/software/make/manual/html_node/Simple-Makefile.html>.

- Definieer een regel om een tekenreeks te tonen:

```makefile
all:
        echo "Hello World"
```
